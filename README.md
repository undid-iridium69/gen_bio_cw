# gen_bio_cw
Repository for files generated during the genome biology coursework

ALignment folder contains all aligned homologs with cox1 gene from our organism
Assembly contains the assembled final genome 
Cox1_sequence has the Cox1 gene of the organism in NT and AA bases
FASTQC results contain both trimmed and raw fastqc results from the reads
PROKKA results (annotations) contain the results from Prokka, including the final table in .tssv used to search for Carbon fixation genes
Phylogeny has the original as well as annotated treefiles, as well as svgs of the tree rooted at Archaea, Bacteria and Eukarya, as discussed in the assessmet
Tables contains the excel table with descriptions and proverties (% identity, E-value of  the collected homologs as well as hyperlinked accession numbers)
cox1 homologs contains the individual fasta files with amino acid sequences of all 17 species' Cox1 genes.
